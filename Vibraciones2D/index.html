Modos blandos del modelo ideal

Con resortes centrales solamente entre primeros vecinos, Ωx = 0 cuando kx = 0 y Ωy = 0 cuando ky = 0, aunque la otra componente de k no sea nula. La red carece de rigidez lineal frente a esos desplazamientos transversales; no es un error de la gráfica.
